# ระบบค้นหาข้อมูลพนักงาน

เว็บแอปภายในองค์กรสำหรับค้นหาชื่อ เบอร์โทร อีเมล ตำแหน่ง หน่วยงาน ตึก และชั้น พร้อมระบบนำเข้า Excel หลายไฟล์และอ่านทุกชีต

## เริ่มใช้งานด้วย Docker

1. คัดลอก `.env.example` เป็น `.env`
2. เปลี่ยน `POSTGRES_PASSWORD`, `DATABASE_URL`, `SECRET_KEY` และ `ADMIN_PASSWORD` ให้เป็นค่าที่ปลอดภัย โดยรหัสผ่านใน `DATABASE_URL` ต้องตรงกับ `POSTGRES_PASSWORD`
3. รัน `docker compose up --build -d`
4. เปิด `http://localhost:8000` แล้วเข้าสู่ระบบด้วย `ADMIN_USERNAME` และ `ADMIN_PASSWORD`

ฐานข้อมูลและไฟล์อัปโหลดอยู่ใน Docker volumes แยกจาก container การอัปเดต image จึงไม่ลบข้อมูลเดิม ก่อนใช้งานจริงควรวาง reverse proxy ที่เปิด HTTPS และตั้ง `SESSION_HTTPS_ONLY=true`

## ขั้นตอนนำเข้าข้อมูล

1. Admin เปิดเมนู **นำเข้าข้อมูล** และเลือกไฟล์ `.xlsx` ได้หลายไฟล์
2. ระบบอ่านทุกชีตและจัดประเภททุกแถวที่มีข้อมูลเป็นพนักงาน หัวตาราง หัวข้อ หมายเหตุ หรือรายการที่ต้องตรวจ
3. ตรวจจำนวนแถว รายชื่อ และค่าตึก/ชั้นที่ระบบตรวจพบ แก้ไขเป็นรายชีตได้
4. กด **เผยแพร่ข้อมูล** ระบบจะแทน snapshot เดิมเฉพาะตึกและชื่อชีตเดียวกัน
5. หากต้องการคืนข้อมูลรุ่นก่อน ใช้ปุ่ม **ย้อนกลับ** ที่หน้าประวัติ

การรวมบุคคลใช้อีเมลเป็นหลัก หากไม่มีอีเมลจะใช้ชื่อกับเบอร์โทรหรือเบอร์ต่อ รายการที่ไม่ชัดเจนจะติดสถานะรอตรวจสอบและเก็บแถวต้นฉบับไว้เสมอ

## พัฒนาและทดสอบ

ติดตั้ง Python 3.12 แล้วรัน:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
$env:DATABASE_URL = "sqlite+pysqlite:///./test.db"
alembic upgrade head
pytest
uvicorn app.main:app --reload
```

ชุดทดสอบจะตรวจตัวแยก Excel, การรวมอีเมลซ้ำ, snapshot/rollback, การล็อกอิน และสิทธิ์ Admin หากไฟล์ตัวอย่างสองไฟล์ยังอยู่ที่ตำแหน่งเดิม จะตรวจครบ 39 ชีตและยืนยันว่าชีตตึก 524 ในไฟล์ตึก 448 ถูกจัดเข้าตึก 524

## สำรองข้อมูล

- ฐานข้อมูล: ใช้ `pg_dump` สำรองฐานข้อมูล `employee_directory`
- ไฟล์ต้นทาง: สำรอง Docker volume `uploads_data`
- ควรสำรองทั้งสองส่วนในรอบเวลาเดียวกัน เพื่อให้ประวัติการนำเข้าตรงกับไฟล์ต้นทาง
